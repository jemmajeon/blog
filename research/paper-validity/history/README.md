# history/ — 세션 전체 기록

이 디렉토리는 두 부분이다.

| 항목 | 위치 | 상태 |
|---|---|---|
| 커밋 히스토리 | `COMMITS.md` | 저장소에 있음 |
| 세션 트랜스크립트 (9.3MB, 대화·도구 호출 전량) | `session_transcript.jsonl` | **보류** — 공개 저장소에 올릴 수 없음 |
| 에이전트 트랜스크립트 54개 (공격 라운드 전량) | `agents/*.output` | **보류** — 동일 |
| 스크래치패드 산출물 (설계 초안·린터 초판·회의 브리프) | `scratchpad/` | **보류** — 동일 |

보류 이유: `jemmajeon/blog`는 **공개** 저장소이고 트랜스크립트 16개 파일에 네이처 논문 원문이 대량 포함된다(재배포 불가).
내부 프록시 호스트는 `<REDACTED_PROXY>`로 치환했고 키·토큰 패턴은 0건이다.
비공개 저장소가 정해지면 `history/` 아래로 그대로 들어간다. 그 전까지 이 파일들은 세션 스크래치패드(휘발)에만 있다.
