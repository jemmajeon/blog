# 논문 타당성 게이트 세트

Nature 논문 1편의 논리구조를 적대적으로 감사하고, 그 감사를 자기 설계에 되돌려
적용하는 과정에서 나온 **재사용 가능한 게이트 집합**이다.
어떤 논문에도 붙는다. `design_v*.md`는 방법을 시험한 시험체이며 산출물이 아니다.

## 먼저 읽을 것
| 파일 | 내용 |
|---|---|
| `DEFENSE_STRATEGY.md` | 3층 방어(기계·선언·자원)와 공격 유형의 층별 배정 실측 |
| `ERROR_LEDGER.md` | 저자 자신의 거짓·과대 진술 12건 전수 대장과 기계검출 가능성 |
| `REVISION_POLICY.md` | 규칙 R1–R23, 회귀 대장 REG-001–008 (수정이 원래보다 나빠진 사례) |
| `S4_final_report.md` | 대상 논문 감사 결과 (확정 FATAL 3건, 축자 인용 포함) |

## 실행 가능한 게이트
| 스크립트 | 규칙 | 검증 상태 |
|---|---|---|
| `paper_lint.py` | 배수 산술·범주 수·불확실성 단위 | **교정 완료.** 238,480자에서 확정결함 재현 |
| `manuscript_gate.py` | R18 맨 숫자 금지 / R19 파생량 손서술 금지 / R21 경계 라벨 | R19 교정 완료, R18 오양성 잔존 |

```
python3 paper_lint.py <원고.md>
python3 manuscript_gate.py <원고.md>
python3 rule_check.py
python3 design_lint.py design_v4.md
```

## 실측된 것 (추정이 아님)
- 논리구조 공격의 **58%가 기계층** — 두 독립 측정(n=19, n=12)에서 동일
- 저자 자신의 오류 **12건 중 11건이 기계 게이트 사정권** (분모는 관측 불가)
- **선언층 적중률 8%** — 사전 등록만으로는 닫히지 않는다 (추정 ~100%는 반증됨)
- 재작성 반복은 점수를 올리지 않았다: **82 → 82 → 80**

## 핵심 한계 (숨기지 않음)
1. 오류 대장의 **분모는 관측 불가**하다. 발견되지 않은 거짓의 수는 알 수 없다.
   → R22(자기 최종검사 금지)만이 구조적 대응이며 사람이 필요하다.
2. 게이트를 만드는 행위도 오류의 대상이다 (E11·E12). → R23(게이트 교정 의무).
3. 연구 질문의 가치나 구성개념 조작화에 대한 이견은 어느 층도 막지 못한다.
   그것은 결함이 아니라 과학이다.
