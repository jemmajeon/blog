# 논문 타당성 게이트 세트

Nature 논문 1편의 논리구조를 적대적으로 감사하고, 그 감사를 자기 설계에 되돌려
적용하는 과정에서 나온 **재사용 가능한 게이트 집합**이다. 어떤 논문에도 붙는다.
`design_v*.md`는 방법을 시험한 시험체이며 산출물이 아니다.

## 빠른 실행

```bash
python3 validate_gates.py            # R23 교정 하네스 — 전체 게이트 자기검증 (15개 기대값)
python3 gates/build_manuscript.py <템플릿.md> <registry.json> [out.md]
python3 gates/manuscript_gate.py <원고.md>            # 규율 하 원고 (strict)
python3 gates/manuscript_gate.py --audit <원고.md>    # 규율 밖 원고 (이행률만)
python3 gates/cite_gate.py <citations.json> <출처루트>
python3 rule_check.py                # 판정규칙 배타성
python3 paper_lint.py <원고.md>       # 배수/범주수/불확실성 단위
python3 design_lint.py design_v5.md --baseline=v3   # 설계문서 린트 L1–L12 (R27 기준선 명시)
python3 obligation_diff.py design_v4.md design_v5.md  # R15 의무 추적 후보
```

CI가 매 푸시마다 R23 조건을 재확인한다 → `.github/workflows/paper-validity-gates.yml`

## 실측된 것 (추정이 아님)

- 논리구조 공격의 **58%가 기계층** — 두 독립 측정(n=19, n=12)에서 동일
- 저자 자신의 오류 **16건 중 15건이 기계 게이트 사정권**
- **선언층 적중률 8%** — 사전 등록만으로는 닫히지 않는다 (추정 ~100%는 반증됨)
- 재작성 반복은 점수를 올리지 않았다: **82 → 82 → 80** (v5는 독립 공격 후에만 실측 — R14)
- 게이트 구축 구간에서 오류가 가장 많이 났다 (16건 중 6건 = 38%).
  그중 2건은 게이트/하네스 자신이 잡았고, 4건은 사람 눈이 잡았다.

## 핵심 한계 (숨기지 않음)

1. **오류 대장의 분모는 관측 불가**하다. 발견되지 않은 거짓의 수는 알 수 없다.
   따라서 "15/16"은 검출률이 아니라 *검출된 것 중* 기계화 가능 비율이다.
   → R22(자기 최종검사 금지)만이 구조적 대응이며 **사람이 필요하다.**
2. **픽스처는 저자가 썼다.** 게이트는 저자가 생각해낸 결함 유형만 잡는다.
   미지의 결함 유형을 잡는다는 보장은 없다.
3. 연구 질문의 가치나 구성개념 조작화에 대한 이견은 어느 층도 막지 못한다.
   그것은 결함이 아니라 과학이다.

## 인용된 제3자 자료

`fixtures/source_excerpt.md`는 게이트 검증용 **단문 발췌**(701바이트)이며 전문을
재배포하지 않는다. 출처: Miao et al., Nature (2026), doi:10.1038/s41586-026-11044-y.
전문 대조가 필요하면 자신의 합법적 사본을 출처 루트로 지정해 사용한다.
