# design_v3 미해결 결함 요약 (위원단 브리핑용)
세 차례 적대적 심사(에이전트 20기)를 거쳐 남은 것. FATAL 0, 중복제거 MAJOR 9.

## 배경
연구 질문: "논문의 코드를 MCP 프로토콜로 포장한 AI 에이전트가, 같은 오프라인 예산으로
검증된 함수 라이브러리만 가진 베이스라인보다 과제 정확도가 높은가?"
형식: 등록보고서(Registered Report) Stage 1. 데이터 수집 전.
설계자 = 시험 대상 방법의 이해관계자. 이 점이 여러 결함의 뿌리.

## 미해결 결함 9건

### D1. 맹검 검증 게이트가 비진단적 (검증 완료, 신뢰도 90)
현행 §7: "판정자 3인이 정규화된 응답 400건의 팔을 추측. **추측 정확도 95% CI 상한이
우연 수준을 넘지 않을 때만** 사람 채점 허용."
→ 산술 검증 결과: 맹검이 완벽해도(참값 0.5) CI 상한 0.549 > 0.5 이므로 실패.
   통과하려면 추측 정확도 ≤ 0.4512 (우연보다 유의하게 나쁨). 완벽 맹검 시 통과율 2.6%.
   맹검 완벽/누출 양쪽에서 모두 실패 → 아무것도 측정하지 못함.
이전 버전은 반대 방향("누출이 입증돼야 무효화")이었고, 그때는 낮은 검정력이 선호 분기를 보존했다.
**두 방향 모두 실패했다. 제3의 방법이 필요하다.**

### D2. 양 팔 모두 0점인 항목이 검정력 모델에 부재 (검증 완료, 82)
그림형 답·NO-REF 항목은 양 팔 모두 0점 → 대응 설계의 불일치쌍 기여가 0.
f=10%면 검정력 0.800→0.758, f=20%면 0.708. `power.yaml` 입력에 이 항이 없다.
§2.2는 항목 교체를 금지, §12는 코퍼스 확장을 금지 → 보정 수단이 없다.

### D3. NO-REF 하위집합이 주 종점을 오염 (80)
"라이브러리로 답할 수 없음"이 정답인 항목(최대 20%)은 분석 정확도가 아니라 **거부 보정**을
측정한다. 처리(팔 A)가 디스커버리 계층이므로 구조적으로 유리.
산술: NO-REF 20% × 거부정확도 격차 40%p = 8%p = 탐지 목표 전체.
즉 "분석을 잘하는가"가 아니라 "자기 도구 목록을 아는가"가 결론을 만들 수 있다.

### D4. 처리 정의가 복합적 (compound treatment)
팔 A = 검증된 함수 라이브러리 + MCP 등록·스키마·디스커버리 계층
팔 B = 검증된 함수 라이브러리 + 호출 문서
"프로토콜 포장의 순효과"라 명명했으나, 포장은 여러 구성요소의 묶음이며 분해되지 않는다.
또한 양 팔이 같은 함수를 가지면 기대 효과가 0에 가까울 수 있고, 설계는 등가성 한계(equivalence
margin)를 등록하지 않아 "CI가 0을 포함"을 **반증**이라 부른다(비결정과 반증을 구분 못 함).

### D5. 설계자가 도구를 저작 (구조적)
평정자는 전원 외부이나 그들의 도구(채점 rubric, 코딩 매뉴얼, 판정 체크리스트, 작성 지침,
임계값)는 전부 설계자 저작. §15는 "파일럿 이전 해시 커밋"으로 시점만 묶을 뿐 독립성을 주지 않는다.
설계자는 요구사항을 쓰고, 외부인을 선발·브리핑·교육·지급한다.

### D6. 보정 세트가 미등록 (88)
§3이 "파일럿이 아닌 별도 보정 세트"라 선언해 §15 구속을 면제받는다. 그 안에서 팔 A·B
채택 빌드 선택(best-of-3), 채점 도구 선택, 채점자 교체가 일어난다. 구성·크기·주 코퍼스와의
분리·선택 지표·수행 주체 전부 미명시.

### D7. "라이브러리"의 지시대상 모호 (검증 완료)
정답 산출 조항이 "독립 분석자가 라이브러리를 직접 사용해 산출. **생성된 MCP 도구** 사용 금지"인데,
'라이브러리'가 (a)상류 저장소 라이브러리인지 (b)양 팔이 생성한 함수 라이브러리인지 불명.
(b)면 정답이 시험 대상 산물로 만들어진다.

### D8. 자기모순 — 침묵결함 결과의 지위
§1: 침묵결함은 "주 결론에 쓰지 않는다" / §9: "결론 문단에 반드시 병기한다". 양립 불가.
또한 전파율 상한(20%)이 검출률 ≥80%면 자동 충족된다(둘이 상호배타적이므로).

### D9. 검정력 모델 ≠ 확증 검정 절차
검정력 0.800은 McNemar 닫힌형으로 산출. 반증 판정은 논문 단위 BCa 군집 부트스트랩.
두 절차의 등가성이 어디에도 확립돼 있지 않다. 또 p_d를 "파일럿 또는 문헌"에서 얻으라는
조항이, `power.yaml`을 파일럿 이전에 커밋하라는 조항과 충돌한다.

## 관찰된 메타 문제
v1→v2: 18건 수정 → 11건 신규 발생
v2→v3: 27건 수정 → 11건 신규 발생
