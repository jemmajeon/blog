## 1. 단일 주 가설 (H1) — 종점 하나만 남긴다
> **H1**: 사전 판정된 "실행 가능 코드 동반" 논문 모집단에서, MCP 도구 에이전트는 **동일 오프라인 예산을 받은 저장소 접근 베이스라인**보다 **T3 과제 정확도**가 높다.

- **주 종점 = T3 정확도 차이. 단 하나.** (v1의 "종단 정확도"는 부 종점으로 강등)
- **반증 조건**: T3 정확도 차이의 95% 군집 부트스트랩 CI가 0을 포함하면 H1 기각. 기각도 그대로 발표.
- **확증 검정은 1개**이므로 다중성 보정 불필요. T1·T2·ITT·비용·지연·침묵결함·개입원장은 **전부 secondary/exploratory**로 표기하며 주 결론에 쓰지 않는다. §2.3 층화 보고도 **사전 등록된 secondary**로 명시한다.

## 2. 순환 차단

### 2.1 봉인 분할 (유지)
파이프라인 실행 전 튜토리얼 열거·무작위 분할. 시드·파일 해시를 등록 시 공개 커밋. 사후 변경 불가.

### 2.2 계층 정의 — 생성물 참조 제거
| 계층 | 정의 (파이프라인 산출물을 **참조하지 않음**) | 역할 |
|---|---|---|
| **T1 재현** | 봉인 튜토리얼 셀의 재현 | secondary |
| **T2 모수 이동** | 구성 튜토리얼의 **관측 인자 범위 밖** 인자. 작성자: 외부 분석자 2인, 도구 목록 비접근 | secondary |
| **T3 조합** | **논문 Methods가 서로 다른 절로 분리 제시한 분석 2개 이상을 결합해야 답이 나오는 과제.** 판정 근거는 논문 텍스트뿐 | **주 종점** |

- T3 작성: 논문당 도메인 전문가 2인, **논문 Methods만** 열람. 도구 목록·MCP 스펙·저장소 비접근.
- **항목 선별 금지**: 작성된 T3 과제는 도구 커버리지와 **무관하게 전량 채점**한다. 도구가 못 덮어 실패하면 **그것이 결과**이며 0점 산입. 항목 제외를 금지한다.
- T3 과제 집합·작성 지침·작성자 자격을 §13 사전공개에 포함.

### 2.3 잔여 오염의 정량화 + **처분 규칙**
- **API 표면 중복도**를 저장소별로 계산(봉인 과제 호출 함수 ∩ 구성 과제 호출 함수 / 봉인 과제 함수).
- **중복도 ≥ 0.90인 저장소는 T1·T2 주 분석에서 제외**하고 제외 목록·사유를 공개한다. (T3는 함수 중복도와 무관하게 정의되므로 미적용)
- 중복도 구간별 층화는 **사전 등록된 secondary**.

### 2.4 네트워크 격리 (신설)
- 구성·평가 전 구간 egress **허용목록 전용**. 대상 저장소의 docs 사이트·GitHub 웹뷰·알려진 미러를 명시 차단.
- 취득한 모든 외부 문서를 해시해 §2.1 커밋 해시와 대조. 일치 시 **오염 기록**.
- **위반 처분 사전 명시**: 오염 확인된 저장소는 주 분석에서 제외, 제외 목록 공개. 오염율이 전체의 10%를 넘으면 **연구 전체를 무효 선언**하고 그 사실을 발표한다.
- 접근 로그를 파일·네트워크 양쪽으로 수집. 로그는 검출 도구일 뿐 비접근을 증명하지 못함을 본문에 명시한다.
- **사전학습 오염은 통제 불가능함을 한계로 명시**한다. 모델 학습 시점 이후 공개된 저장소 부분표본(n=40)에서 T3 정확도를 별도 보고한다(secondary).

### 2.5 정답 출처 (신설)
- T1 정답: 봉인 튜토리얼 셀 출력.
- **T2·T3 정답: 독립 인간 분석자 2인이 라이브러리를 직접 사용해 산출.** 생성된 MCP 도구 사용 **금지**.
- 정답 산출은 **어느 팔의 실행보다 먼저** 완료하고 정답 집합을 **해시 커밋**.
- 정답 산출자 ≠ T3 작성자. 양측 모두 도구 목록 비접근. 산출 코드·절차를 §13에 포함.

## 3. 세 개의 팔

| 팔 | 저장소 | 구성 튜토리얼 | 봉인 | 환경 | **오프라인 준비** | 질의시점 예산 |
|---|---|---|---|---|---|---|
| **A 도구** | 동일 클론 | 접근 | 격리 | 제공 | MCP 도구 생성 (예산 O) | 동일 |
| **B 동일-오프라인** | 동일 클론 | 접근 | 격리 | 제공 | **동일 예산 O로 자유 준비**(색인·요약·노트). MCP 생성 금지 | 동일 |
| **C 무준비** | 동일 클론 | 접근 | 격리 | 제공 | 없음 | 동일 |

- **주 비교 = A vs B.** (오프라인 연산을 동일화한 비교 — H1이 측정하려는 것)
- A vs C는 secondary (오프라인 준비 전체의 효과).
- **오프라인 예산 O**: 논문당 토큰 1,500만, 벽시계 4시간. 실제 소비량을 양 팔 모두 보고.
- 프롬프트는 **도구 인터페이스 안내 문장을 제외하고 동일**. 한쪽만의 금지 조항 없음. 세 프롬프트 diff 전문을 부록 게재. *(v1에서 공격 실패 확인된 조항 — 유지)*
- **질의시점 예산 (수치 확정)**: 질의당 토큰 200,000 / 벽시계 10분 / 재시도 3회.
- **민감도 분석 사전 등록**: 위 예산의 0.5배·1배·2배 3수준에서 주 비교를 반복하고 **전부 보고**한다. 특정 수준에서만 효과가 나타나면 그 사실을 결론에 포함한다.

## 4. 검증 기준의 코드화
- 모든 통과 기준을 `validation.yaml`에 **수치로** 고정, 버전 태그와 함께 공개. Methods의 임계값 표는 이 파일에서 자동 생성.
- 수치 비교: 상대오차 단일 정의 `|a-b|/max(|b|,ε) < 0.01`, ε=1e-12. "exactly (with tolerance)" 류 표현 금지.
- **그림**: 플롯 원천 배열을 직렬화해 수치 비교.
  - 원천 배열을 노출하지 않는 과제는 **주 분석에서 제외**하고 제외 건수·사유를 보고한다(secondary로 별도 취급).
  - 이미지 비교를 쓰는 경우에 한해: 라벨쌍 집합(일치 300쌍·불일치 300쌍)과 **목표 FPR = 0.01**을 **등록 시점에 사전 공개**하고, 라벨 작성자는 **외부·팔 맹검**으로 한다. 사후 임계값 선택을 금지한다.

## 5. 불확실성 — 단일 구성
- **주 CI = 논문 단위 군집 부트스트랩(10,000 재표본, BCa 보정).** 주 종점의 권위 있는 구간은 이것 **하나**다.
- 정확 이항 CI는 **단일 팔 비율의 기술 통계로만** 사용하며, **주 비교 차이에는 사용하지 않는다.** 충돌 시 군집 부트스트랩이 우선한다.
- "± 0.0%" 보고 금지. 비율은 항상 n 병기.
- 실행 간 변동·채점자 변동은 **분산성분표로 별도 보고**하며 주 CI와 섞지 않는다.
- 재표본 해상도 미만 p값은 "p < 1/재표본수"로만 표기.

## 6. 파생 수치·구성 수의 자동화
- 모든 배수·비율·증감은 결과 테이블에서 **스크립트가 계산**해 원고에 주입한다. (F5의 실질 방어)
- **검산기 규칙 구체화**: 원고의 모든 수치는 결과 테이블의 **명명된 셀에 매크로로 결속**되어야 한다. 단순 존재 검사가 아니다. 결속되지 않은 리터럴 수치가 있으면 빌드 실패.
  - 적용 범위: 본문·초록·그림범례·표·부록 **전부**.
  - 반올림 표기는 매크로에 자릿수 인자로 지정한다(예: `\num{tbl:main.speedup}{1}`).
  - **정성 표현 금지 목록**: "약 N배", "거의 두 배" 등 수치를 함축하는 정성 표현을 금지하고, 반드시 결속 매크로로 쓴다.
- 실험 구성은 `experiments.yaml`에 열거하며 본문의 범주·구성 수 문장은 레지스트리에서 자동 생성한다.

## 7. 맹검 — 실효성까지 검증
- 응답 정규화기가 최종 답변 필드만 남기고 팔 식별 흔적을 제거한다. 제거 대상을 **열거형이 아니라 규칙형**으로 정의: 도구명·코드블록·MCP 언급 + **유효숫자 자릿수 표준화** + **길이 절단(공통 상한)** + 정형 템플릿 재작성.
- **맹검 무결성 검사 (신설)**: 외부 판정자 3인이 정규화된 응답 200건의 **팔을 추측**한다. 추측 정확도의 95% CI 하한이 **우연 수준(1/3)을 초과하면 해당 과제군의 사람 채점을 무효화**하고 **자동 정확일치 채점으로 전환**한다.
- 채점자: 저자단 **외부**. 보정 세트에서 일치도 측정 후 투입하며, **κ < 0.75면 재훈련 또는 교체**(게이트에 수치를 부여).
- 채점자는 정규화된 답변과 무작위 ID만 본다. 불일치는 **제3 채점자 판정**으로 해소하고 "합의까지 토론"을 쓰지 않는다. 독립 평정 기록 보존.
- 코드 제출 필수 과제는 **자동 정확일치 채점만** 사용한다.

## 8. 모집단과 ITT
- **모집단 판정 (신설)**: 무필터 연속 표집 후, **파이프라인과 무관한 사전 체크리스트**로 "실행 가능 코드 동반" 여부를 판정한다(실행 가능 스크립트/노트북 존재 + 데이터 접근 가능 + 라이선스 허용). 판정자는 외부 2인이며 **파이프라인 결과를 모른다**. κ를 보고한다.
- **H1 모집단 = 이 판정을 통과한 논문.** 주 종점은 이 집합에서 계산한다. 가설 모집단과 추정 모집단을 일치시킨다.
- **0점 귀속 명확화**: "에이전트화 실패"는 **팔 A에만 정의되는 사건**이며 0점은 **팔 A에만** 부과한다. 팔 B·C는 해당 논문을 **정상 시도**한다. "동일 전체 집합"은 **분모 동일**을 뜻한다.
- "에이전트화 실패"의 조작적 정의를 `validation.yaml`에 수치로 고정한다(도구 0개 생성 또는 전 도구 검증 실패).
- 무필터 전체 집합에 대한 ITT 결과는 **secondary**로 별도 보고한다.

## 9. 침묵 결함 주입 — 검출 종점 정의 (secondary)
- 주입 유형(사전 고정): ①효과대립유전자 뒤바꿈 ②좌표 off-by-one ③다중검정 보정 제거 ④정규화 상수 오류 ⑤공변량 누락. 저장소 3개 × 5유형 = **15구성**(레지스트리 등록).
- **검출 정의**: 에이전트 출력이 **해당 결함의 위치 또는 성질을 명시적으로 지시**한 경우만 검출로 센다. 단순 실행 실패·모호한 경고("결과가 이상함")는 **비검출**.
- **판정자**: 외부 2인, 주입 여부 맹검. 불일치는 제3 판정.
- **분모**: 주입 구성 15개 × 과제 수.
- **무주입 대조군 (신설)**: 동일 과제를 결함 없는 저장소에서 실행해 **오경보율**을 측정한다. 검출률은 반드시 오경보율과 **쌍으로만** 보고한다.
- 낮은 검출률은 부정적 결과로 그대로 보고한다. 실행 오류 주입 결과와 **합산하지 않는다**.

## 10. 자율성 — 측정 (secondary)
- "autonomous" 서술어를 사용하지 않는다.
- 모든 인간 메시지를 기록하고 4분류: `pointer` / `parameter` / `analytic-content` / `correction`.
- **코딩 매뉴얼을 사전 등록**한다: 각 분류의 판정 규칙 + 경계 사례 20건의 정답 라벨. 명시 규칙 예 — "분석 선택을 좁히는 자원 지정은 `pointer`가 아니라 `analytic-content`", "수치 설정값 제공은 그 값이 결과를 좌우하면 `analytic-content`".
- **코더**: 외부 2인, 팔 맹검(가능한 범위에서). **코더 간 κ를 보고하며 κ < 0.75면 매뉴얼 개정 후 재코딩.** 불일치는 제3 코더 판정.
- **4개 분류 전부 보고**한다(주 지표만 보고해 경계 사례를 숨기는 것을 금지).
- "무개입(unassisted)" 표기는 `analytic-content` = 0 **AND** `correction` = 0 **AND** `parameter` = 0 인 분석에만 사용한다.
- 원장 코딩은 팔 식별이 구조적으로 불가피함을 **한계로 명시**한다.

## 11. 재현성 척도 주장 — 수치 게이트 (secondary)
- "에이전트화 용이성 = 재현성 척도"를 **주장하지 않는다.**
- 검증 조건: 부분표본 n=60(v1의 30에서 증량)에 대해 **파이프라인 결과를 모르는 인간 재현자**가 독립 재현을 시도한다.
  - **인간 재현자의 성공 기준 명시**: 논문의 주 그림/표 1건을 상대오차 1% 내로 재생산.
  - **예산 명시**: 논문당 8시간, 외부 대학원생 수준 2인.
- **게이트에 수치 부여**: κ의 95% CI **하한이 0.60을 초과**할 때만 정책 권고를 한다. κ를 제시하는 것만으로는 게이트를 통과하지 못한다.
- 이 조건 미달 시 "agent availability" 류 정책 권고를 **일절 하지 않는다**.

## 12. 표본·검정력 — 수치 명시
- **코퍼스**: bioRxiv bioinformatics, 2026-01-01~06-30 **연속 표집 240편** (문서화 품질·유지보수 상태 무필터).
- §8 판정 통과 예상 비율 0.60 → **H1 모집단 ≈ 144편**.
- **T3 항목 수 사전 고정: 논문당 4개** → 약 576항목. (작성자에게 쿼터를 부여해 항목 수가 연구 결과가 되지 않게 한다)
- **검정력 가정 명시**: ICC = 0.15, 논문당 4항목 → 설계효과 1 + (4−1)×0.15 = **1.45** → 유효 항목 ≈ 397.
- 대응 설계(동일 항목을 A·B 양 팔에 제시). 기준 정확도 0.60, 탐지 목표 차이 **8%p**, α=0.05 양측, 검정력 0.80.
- **최소 군집 수 사전 고정: 논문 ≥ 120편.** 미달 시 군집 부트스트랩의 과소 피복을 이유로 주 검정을 수행하지 않고 그 사실을 발표한다.
- **소표본 보정**: BCa. 군집 수가 120~150인 구간에서는 와일드 군집 부트스트랩을 병기한다.
- **검정력 산출 스크립트를 등록 시점에 공개**한다(계산 재현 가능, Stage 1 심사자가 검산 가능).
- 정지규칙: 사전 산출 표본 도달 시 종료. **중간 분석 없음.**

## 14. 스스로 명시하는 한계 (주장하지 않는 것)
- 사전학습 오염은 통제 불가. 부분표본 분석으로 **추정만** 한다.
- 접근 로그는 비접근을 **증명하지 못한다**. 검출 도구일 뿐이다.
- 개입원장 코딩의 팔 맹검은 구조적으로 불완전하다.
- T3는 "논문 내 분리 제시 분석의 결합"으로 정의된 **조작적** 분포밖이며, 절대적 분포밖이 아니다.
- 본 설계는 A vs B 비교로 "MCP 도구화의 순효과"를 측정한다. 오프라인 연산 자체의 가치는 A vs C로 분리하나, **두 효과의 상호작용은 추정하지 않는다.**
