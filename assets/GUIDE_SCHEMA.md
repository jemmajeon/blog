# 안내서 데이터 형식 (restaurant/*.json 등)

안내서 페이지(`restaurant/<slug>.html`)는 같은 이름의 `<slug>.json`을 읽어 `assets/guide.js`가 그린다.
글을 고칠 때는 JSON만 고친다. HTML은 3줄짜리 껍데기다.

## 선택 필드 (2026-11 개편)

```jsonc
{
  "hero": "hero",                       // 맨 위 큰 사진 = images 의 키
  "images": {                           // 사진 목록. src 는 안내서 HTML 기준 상대 경로
    "beef": { "src": "img/food-beef.jpg", "title": "원본 파일 이름", "page": "https://commons.wikimedia.org/...",
              "license": "CC BY-SA 4.0", "artist": "작가" } },
  "tabs": [                             // 있으면 섹션을 가로 탭으로 나눈다 (가로 탭은 1단만)
    { "id": "rec", "label": "🏆 추천", "sections": ["pick", "day"] } ],   // 섹션이 3개 이상이면 탭 안에 바로가기
  "sections": [
    { "id": "beef", "type": "places", "img": "beef",          // 섹션 기본 사진
      "places": [{ "name": "...", "img": "beef",               // 장소 사진 (없으면 섹션 기본 사진)
                   "price": "1인 29,000원 / 4인 총 116,000원 (저녁, 주말)",   // 이 모양이면 1인/4인 가격 상자로 그린다
                   "notes": [["주차", "..."], ["좋다는 후기", "..."], ["아쉽다는 후기", "..."], ["후기", "..."], ["확인 필요", "..."]] }] },
    { "id": "compare", "type": "bars", "items": [              // 금액 막대 (value 큰 값 기준 길이)
      { "label": "식당", "sub": "메뉴", "text": "1인 29,000원 / 4인 116,000원", "value": 116000, "hl": true }] },
    { "id": "call", "type": "list", "style": "check", "items": ["..."] }   // style: check (체크 칸) | muted (흐리게)
  ]
}
```

- notes 의 `주차`는 주소 아래 줄로, `좋다는 후기`, `아쉽다는 후기`, `후기`는 색 상자로, `확인 필요`는 강조 줄로 나온다. 나머지 메모와 menu 는 '더 보기'로 접힌다 (메모 2개 이하이고 menu 가 없으면 펼친 채로).
- 사진은 직접 찍었거나 재사용이 허락된 것만 (위키미디어 공용 CC0, CC BY, CC BY-SA 등). 가게 사진을 퍼오지 않는다. 메뉴 참고 사진에는 화면에 '참고 이미지'가 붙고, 바닥글에 출처가 나온다.

규칙
- 장소(가게) 정보는 공개 정보라 그대로 둔다. **사람 이름·가족 관계·개인 연락처는 넣지 않는다** ("친구", "동창" 정도로).
- 원문 내용을 빠뜨리지 않는다. 형식에 안 맞는 내용은 `type: "list"` 섹션이나 `notes`로 옮긴다.
- 이미지가 깨진 것(빈 src)은 넣지 않는다.
- 값이 없는 필드는 아예 빼도 된다.
