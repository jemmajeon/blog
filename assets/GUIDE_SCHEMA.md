# 안내서 데이터 형식 (restaurant/*.json 등)

안내서 페이지(`restaurant/<slug>.html`)는 같은 이름의 `<slug>.json`을 읽어 `assets/guide.js`가 그린다.
글을 고칠 때는 JSON만 고친다. HTML은 3줄짜리 껍데기다.

```jsonc
{
  "title": "가산디지털단지 청첩장 모임",          // 짧은 제목
  "subtitle": "결혼 소식 전하는 축하 자리",        // 한 줄 설명
  "kind": "모임",                                // 모임 | 나들이 | 여행 | 생활
  "date": "2026-07-01",                          // 모임/방문 날짜 (지나면 '지난 안내' 표시)
  "time": "18:30",                               // 선택
  "area": "가산디지털단지",                        // 지역
  "source": "식신 · 다이닝코드 · 매장 공식정보 (2026.06 기준)",  // 조사 기준
  "summary": ["룸·코스가 있는 식당 위주", "2차는 걸어서 5분 카페"],   // 한눈에 (2~5줄)
  "sections": [
    { "id": "dining", "title": "🥂 분위기 식당", "intro": "선택 문단", "type": "places",
      "places": [
        { "name": "포타제 (Potager)", "kind": "프렌치·이탈리안 코스",
          "tags": ["코스요리", "예약 필수"],
          "address": "금천구 디지털로9길 68", "hours": "평일 11:30-21:00 · 토·일 휴무",
          "price": "코스 1인 50,000원~", "phone": "02-000-0000",
          "menu": [["시그니처 디너 코스", "디너"], ["콜키지", "무료"]],
          "notes": [["분위기", "화이트톤, 테이블 간격 넉넉"], ["추천", "가장 격식 있는 자리"]],
          "rating": "4.4/5.0",
          "links": [{ "label": "네이버지도", "url": "https://map.naver.com/..." }] } ] },
    { "id": "course", "title": "🗺️ 추천 코스", "type": "steps", "intro": "선택",
      "steps": [{ "time": "18:30", "title": "포타제 디너", "text": "설명" }] },
    { "id": "pick", "title": "🏆 MY PICK", "type": "picks",
      "items": [{ "title": "1순위 포타제", "text": "이유" }] },
    { "id": "tips", "title": "💡 팁", "type": "list", "items": ["문장", "문장"] },
    { "id": "compare", "title": "📊 비교", "type": "table",
      "columns": ["식당", "가격", "분위기"], "rows": [["A", "1만", "조용"]] }
  ]
}
```

규칙
- 장소(가게) 정보는 공개 정보라 그대로 둔다. **사람 이름·가족 관계·개인 연락처는 넣지 않는다** ("친구", "동창" 정도로).
- 원문 내용을 빠뜨리지 않는다. 형식에 안 맞는 내용은 `type: "list"` 섹션이나 `notes`로 옮긴다.
- 이미지가 깨진 것(빈 src)은 넣지 않는다.
- 값이 없는 필드는 아예 빼도 된다.
